# Roman Urdu (per surah)

Roman Urdu rendering of Allama Syed Zeeshan Haider Jawadi's Urdu translation, written verse by verse from the Urdu text (not machine-transliterated).

One file per surah: `N.json` is a JSON array with one string per verse, in order. All 114 surahs, 6236 verses. The Qur'an school page loads only the file for the surah being opened.
